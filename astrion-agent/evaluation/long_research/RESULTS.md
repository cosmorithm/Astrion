# 长程科研 Context 对照：试运行记录

日期：2026-11-02。材料为既有 `Agent Test Paper` 本地资料库的原始 PDF 提取内容，三个任务各六篇；单 Agent，`deepseek-flash`，每组独立数据库与上下文，最多 30 次决策，字符水位 16,000，本地输入硬预算 B=12,000 token。每题在第 3、6 次决策前注入同样的用户要求修改；历史重读工具两组均可用。固定 JSON 序列化下的本地计数不是服务端隐藏模板，输出需另留预算。

`legacy` 全程关闭 SS/Planner，使用原有五层 `Memory.compact`，为公平比较在相同 token 水位也主动触发压缩；它不是旧版默认字符触发配置的原样回放。`ss` 采用当前 Step/SS 重构及预算恢复。独立工具调用、数据、工作台均受相同封闭资料工具限制。每题每组一次，后续轨迹自然不同；这不是统计显著的结论。

## 独立复核与费用

程序审查只检查运行状态和引用位置。已有与受测模型同型号、但独立请求的参考裁判：它接收临时要点、论文提取页和答案，验证裁判给出的答案引文确实存在；这些只是辅助判断，不是独立权重或人工结论。参考裁判对若干报告给出未通过提示，部分是未覆盖要点、缺少有效引用或可能无依据的说法；原参考要点中有些超出长任务明确要求，裁判对缺失项判 `incorrect` 不等于输出了错误事实，也不能直接拿来算任务分数。已有人工复核表，需逐条核对报告和原始 PDF。LR01/旧压缩第一次参考裁判因回答引文校验失败，另一次遇余额不足，均保留；其后独立重试完成。

本次研究任务全部尝试已报告 3,845,913 token；固定历史的五次尝试已报告 1,454,090 token；参考裁判十次尝试已报告 221,750 token，总计 **5,521,753 已报告 token**。HTTP 402、网络中断和部分未追踪内部重试可能有未知用量；这不是最终账单。不同组并发，单组耗时不能简单相加为墙钟耗时。

实验过程中工作树已有与本次无关的未提交修改，运行也使用了其中的网络重试逻辑。第一轮 LR01 的报告没有源码哈希；LR02/LR03 的早期运行在实验代码继续修改期间于结束时读取源码哈希，因此其中部分评测脚本/研究入口哈希不能保证等于进程启动时加载的代码。LR01 重测采用启动时捕获的源码哈希。原始报告不回填或改写；不能仅凭 git commit 复现这些运行。干净源码副本的离线测试另行验证。
